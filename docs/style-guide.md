## 1. 원칙

1. **차분한 바탕, 한 가지 강조색**: 화면 대부분은 흰색·회색이고 강조색은 주 행동(저장, 로그인, `+ 새 할일`)과 현재 선택(탭, 뷰 전환)에만 쓴다.
2. **상태는 색 + 텍스트**: 상태 색만으로 구분하지 않고 항상 텍스트 라벨을 함께 둔다 (WF-05 상태 구분, PRD 7장).
3. **선과 여백으로 구분**: 그림자는 떠 있는 요소(대화상자, 모바일 메뉴)에만 쓰고 나머지는 1px 선으로 나눈다.
4. **토큰만 쓴다**: 컴포넌트 CSS에 색·크기 값을 직접 쓰지 않고 2장의 CSS 변수를 쓴다.

### 2.2 글꼴

```css
--font-family: "Pretendard", -apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo",
  "Malgun Gothic", "맑은 고딕", sans-serif;
```

- Pretendard는 설치된 경우에만 쓰고, 웹폰트는 내려받지 않는다. 시스템 글꼴로 대체된다.
- 날짜·기간처럼 자릿수를 맞춰야 하는 숫자에는 `font-variant-numeric: tabular-nums`를 쓴다.

| 토큰 | 크기 / 줄 높이 | 굵기 | 쓰는 곳 |
|------|---------------|------|---------|
| `--text-xs` | 12px / 16px | 400 | 캘린더 칸 막대 글자, 배지 |
| `--text-sm` | 13px / 18px | 400 | 표 본문, 보조 텍스트, 검증 메시지 |
| `--text-md` | 14px / 20px | 400 | 기본 본문, 입력란, 버튼 |
| `--text-lg` | 18px / 26px | 700 | 화면 제목(할일 목록, 설정), 캘린더 기간 표시(2026.11) |
| `--text-xl` | 22px / 30px | 700 | 로그인·회원가입 제목, 헤더 로고 |

- 굵기는 400(본문)과 700(제목·선택된 탭·날짜 숫자 '오늘') 두 가지만 쓴다.
- 모바일(< 768px)에서도 입력란 글자는 16px로 둔다. iOS에서 14px 입력란에 포커스하면 화면이 확대되기 때문이다.

## 4. 컴포넌트

### 4.1 버튼

| 종류 | 모양 | 쓰는 곳 |
|------|------|---------|
| 주 버튼 | `--color-primary` 바탕, 흰 글자, 테두리 없음 | 로그인, 가입하기, 저장, `+ 새 할일`, 추가 |
| 보조 버튼 | 흰 바탕, `--color-border-strong` 1px 테두리, `--color-text` 글자. hover는 `--color-bg-subtle` | 취소, 필터 해제, 오늘, `<` `>` |
| 위험 버튼 | 흰 바탕, `--color-danger` 1px 테두리·글자. 확인 대화상자 안의 실행 버튼만 `--color-danger` 바탕 + 흰 글자 | 삭제 |
| 텍스트 버튼 | 바탕·테두리 없음, `--color-text-muted` 글자, hover 시 `--color-text` | 로그아웃, 닫기, `< 뒤로` |

- 높이 `--control-height`, 좌우 여백 `--space-3`, 모서리 `--radius-md`, 글자 `--text-md`.
- 비활성(저장·로그인 중): 투명도 0.5, `cursor: not-allowed`. 문구는 WF의 '로그인 중...' 등으로 바꾼다.
- 로그인·회원가입·모바일 폼의 주 버튼은 폼 폭을 가득 채운다.

### 4.2 버튼 그룹 (월/주/일 전환)

참고 화면처럼 보조 버튼을 붙여 한 덩어리로 만든다. 안쪽 모서리는 0, 바깥쪽만 `--radius-md`, 버튼 사이는 1px 선 하나. 선택된 버튼은 `--color-primary` 바탕 + 흰 글자. 와이어프레임의 `(o)월 ( )주 ( )일` 라디오는 이 모양으로 그린다.

### 4.3 입력란·드롭다운

- 높이 `--control-height`, `--color-border-strong` 1px 테두리, 모서리 `--radius-md`, 안쪽 여백 `0 --space-2`.
- 포커스: 테두리 `--color-primary`, 바깥 `0 0 0 2px --color-primary-soft`.
- 오류: 테두리 `--color-danger`. 메시지는 입력란 바로 아래 `--space-1` 띄워 `--text-sm`, `--color-danger` (WF 3.2 필드 옆 검증 메시지).
- 라벨은 입력란 위(모바일) 또는 왼쪽 고정 폭 96px(데스크톱 할일 폼·설정). 필수는 라벨 뒤 `*`를 `--color-danger`로.
- 안내 문구(비밀번호 길이 등)는 `--text-sm`, `--color-text-muted`.
- 날짜는 브라우저 기본 date picker를 그대로 쓰고 같은 테두리·높이만 맞춘다 (FR-04).
- 드롭다운은 기본 `<select>`에 같은 테두리를 입힌다.

### 4.4 상태 배지

`<진행 중>` 같은 상태 라벨. 연한 상태색 바탕 + 진한 상태색 글자, `--text-xs`, 700 굵기, 높이 20px, 좌우 `--space-2`, `--radius-sm`. 목록 행·모바일 카드·할일 폼의 '현재 상태'에 쓴다.

### 4.5 표·목록 (WF-03, WF-08)

- 데스크톱 표: 머리 행 `--color-bg-subtle` 바탕, `--text-sm` 700, 높이 36px. 본문 행 높이 44px, 아래 1px `--color-border`. hover는 `--color-primary-soft`, 행 전체가 눌리는 영역이라 `cursor: pointer`.
- 기간 열은 `tabular-nums`로 `YYYY-MM-DD ~ YYYY-MM-DD`를 맞춘다.
- 모바일 카드: 위 줄에 제목(`--text-md` 700)과 오른쪽 배지, 아래 줄에 카테고리·기간(`--text-sm`, muted). 카드 사이 1px 선, 안쪽 여백 `--space-3 --space-4`.
- 빈 상태·결과 없음: 목록 영역 가운데 `--text-md` muted 안내 문구, 그 아래 필요하면 주 버튼 (WF-03 상태).

### 4.6 확인 대화상자 (WF 3.2)

- 바탕을 `rgb(0 0 0 / 40%)`로 덮고 가운데 흰 상자. 폭 360px(모바일은 좌우 `--space-4` 남기고 가득), 안쪽 여백 `--space-5`, `--radius-lg`, `--shadow-pop`.
- 제목 `--text-lg`, 설명 `--text-md` muted, 버튼은 오른쪽 정렬로 `[취소]`(보조) `[삭제]`(위험, 채움) 순서.

### 4.7 로딩

'불러오는 중...' 텍스트 한 줄(`--text-md`, muted)만 쓴다. 스피너·스켈레톤은 두지 않는다 (WF 3.2).

## 5. 캘린더 (WF-05, WF-06)

### 5.1 도구줄

참고 화면 배치를 따른다: 왼쪽에 기간 표시(`2026.11` / `11.02 - 11.08` / `2026.11.03`, `--text-lg`)와 붙은 `<` `>` 버튼, `오늘` 보조 버튼. 가운데 또는 오른쪽에 월/주/일 버튼 그룹(4.2). 모바일은 두 줄(1줄 버튼 그룹, 2줄 이동)로 나눈다.

### 5.2 월간 그리드 (데스크톱·태블릿)

| 요소 | 규칙 |
|------|------|
| 요일 머리 | 높이 32px, `--color-bg-subtle` 바탕, `--text-sm`. 월요일 시작(OI-06), 토요일 `--color-saturday`, 일요일 `--color-sunday` |
| 칸 | 7열 같은 폭, 최소 높이 112px, 1px `--color-border` 격자. 안쪽 여백 `--space-1` |
| 날짜 숫자 | 칸 왼쪽 위, `--text-sm`. 토·일 색은 요일 머리와 같다. 앞뒤 달 날짜는 `--color-text-disabled` |
| 오늘 칸 | 바탕 `--color-today-bg`, 날짜 숫자 700 굵기. 참고 화면처럼 1px `--color-text` 테두리로 한 번 더 표시 |
| 할일 막대 | 높이 20px, 진한 상태색 바탕, 흰 글자 `--text-xs`, `--radius-sm`, 막대 사이 2px. 한 줄 말줄임(`text-overflow: ellipsis`). 막대 안에 제목과 상태 라벨을 함께 쓴다(예: `팀 회의 · 진행 중`). 시작 전 막대는 회색 바탕 |
| 여러 날 할일 | 시작일~종료일의 칸마다 막대를 따로 그린다 (BR-12). 칸을 넘는 한 줄 막대는 그리지 않는다 |
| 칸 한도 | 막대 3개까지, 넘으면 4번째 줄에 `+N개 더`(`--text-xs`, `--color-primary`)를 두고 누르면 그리드 아래 그날 목록을 연다 (NFR-12) |
| 그날 목록 | 그리드 아래, 위 1px 선. 머리 `11월 3일 (화)`(`--text-md` 700), 항목은 4.5 모바일 카드와 같다 |

### 5.3 월간 그리드 (모바일, < 768px)

- 칸 최소 높이 56px, 날짜 숫자 아래 개수를 `(n)` 대신 지름 18px 원 안의 숫자로 쓴다(`--color-primary-soft` 바탕, `--color-primary` 글자, `--text-xs`). 0건이면 비운다 (NFR-12).
- 선택된 날짜는 날짜 숫자를 지름 24px `--color-primary` 원 + 흰 글자로 표시한다. 오늘 칸 배경 규칙은 그대로 둔다.
- 가로 스크롤은 없다. 360px에서 칸 폭은 약 46px이다.

### 5.4 주간·일간 (P1)

- 데스크톱 주간: 월간 칸과 같은 막대 규칙의 7열 한 줄. 머리에 `2 월` 형식(숫자 700 + 요일), 오늘 열 전체에 `--color-today-bg`. 시간 축은 그리지 않고 칸 최소 높이 240px, 칸 한도는 없다.
- 일간·모바일 주간: 4.5 모바일 카드 목록. 모바일 주간의 날짜 머리는 `11-03 (화)`를 `--color-bg-subtle` 띠로 두고, 오늘이면 `오늘`을 `--color-primary` 글자로 붙인다.

### 5.5 카테고리 체크 목록 (FR-11)

- 데스크톱·태블릿: 그리드 왼쪽 폭 200px 세로 목록, 그리드와 사이 `--space-5`. 제목 `카테고리` `--text-md` 700
- 항목: 높이 32px, 체크박스(`accent-color: var(--color-primary)`) + 이름 `--text-md`. 해제된 항목 이름은 `--color-text-muted`
- 맨 아래 입력란(4.3, 폭 100%) + `추가` 보조 버튼, 오류는 입력란 아래(4.3)
- 모바일: 도구줄 위에 놓고 항목을 가로로 줄바꿈해 늘어놓는다(가로 스크롤 없음)

## 7. 반응형

브레이크포인트는 NFR-12를 따른다. 미디어 쿼리는 아래 두 개만 쓴다.

```css
@media (max-width: 767px)  { /* 모바일 */ }
@media (min-width: 1024px) { /* 데스크톱 */ }
```

태블릿(768~1023px)은 기본(데스크톱 구성)에 본문 폭만 줄어든 상태다. 모바일에서 바뀌는 값은 `--control-height` 40px, 입력란 글자 16px, 좌우 여백 `--space-4`, 표 → 카드, 월간 막대 → 개수다.

## 8. 하지 않는 것

- 웹폰트 내려받기, 아이콘 폰트·아이콘 라이브러리 (아이콘이 필요한 곳은 `<` `>` `+` `=` 같은 문자로 대신한다). 예외로 헤더 '설정' 버튼의 기어 기호는 인라인 SVG 하나(16px, `currentColor`)로 그리고 '설정' 문구 왼쪽에 둔다 (사용자 결정(2026-11-05), WF 3.1)
- 애니메이션 (hover 색 전환 `120ms` 외에는 두지 않는다)
- 접근성 별도 대응 (NFR-14 범위 외). 다만 상태는 색 + 텍스트를 지킨다
