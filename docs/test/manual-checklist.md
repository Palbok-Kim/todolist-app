# 수동 체크리스트

QA-07에서 이 표를 위에서부터 수행하고 결과 열을 채운다. 수용 기준 원문은 [도메인 정의서](../1-domain-definition.md) 5장, NFR은 [PRD](../2-prd.md) 5장에 있다(PR-01). 자동 테스트 경로는 `backend/`에서 `npm test`로 함께 실행된다(TQ-05, TQ-07 테스트 이름에 ID 포함).

- 결과 표기: `통과` / `실패(사유)` / `해당 없음(사유)`
- KPI-01은 P0 수용 기준 18개 전부 통과가 기준이다. P1은 구현한 항목만 QA-09에서 확인한다
