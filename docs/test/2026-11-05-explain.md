# DB-09 EXPLAIN 결과 요약 (2026-11-05)

DB-09의 인덱스 사용 확인 기록이다(NFR-05, R-03).

## 측정 환경

- 로컬 PostgreSQL 17(Windows 서비스), 개발 DB `todolist`
- `npm run seed -- load` 데이터: `@example.test` 사용자 1001명(부하 1000 + 수동 확인 계정 1), todos 200,000행, categories 5,001행
- 대상 사용자: `load0500@example.test`(할일 200, 카테고리 5), 오늘 = 2026-11-05(Asia/Seoul)
- 방법: 앱의 실제 쿼리 함수(`todo.queries`·`category.queries`)에 `EXPLAIN (ANALYZE, BUFFERS)`를 붙여 호출. `ANALYZE` 후 한 번 데우고 두 번째 실행을 기록

## 결과

| 쿼리 (함수)                                               | 사용 인덱스                                                                   | 스캔 방식                                         | 반환 행 | 실행 시간 |
| --------------------------------------------------------- | ----------------------------------------------------------------------------- | ------------------------------------------------- | ------- | --------- |
| 목록, 필터 없음 (`todo.listByUser`)                       | `idx_todos_user_id_category_id`                                               | Bitmap Index Scan → Heap                          | 200     | 0.133 ms  |
| 목록, `status=OVERDUE` (`todo.listByUser`)                | `idx_todos_user_id_category_id`                                               | Bitmap Index Scan, 상태는 Filter                  | 82      | 0.097 ms  |
| 목록, 카테고리 + `status=IN_PROGRESS` (`todo.listByUser`) | `idx_todos_user_id_category_id`                                               | Index Scan (user_id, category_id)                 | 1       | 0.028 ms  |
| 캘린더 42일 2026-11-01~12-12 (`todo.listByRange`)         | `idx_todos_user_id_end_date_start_date_created_at`                            | Bitmap Index Scan (user_id, end_date, start_date) | 108     | 0.092 ms  |
| 카테고리 목록 + 할일 수 (`category.listByUser`)           | `uq_categories_user_id_lower_name`, 할일 수는 `idx_todos_user_id_category_id` | Bitmap Index Scan + Index Only Scan(SubPlan)      | 5       | 0.063 ms  |

- 다섯 쿼리 모두 `Seq Scan on todos`가 없다. 정렬은 사용자 한 명의 행(최대 200)만 메모리 quicksort(≤ 49kB)
- 상태 필터는 저장 컬럼이 없어(도메인 4장) `user_id`로 좁힌 뒤 Filter로 판정한다. 사용자당 행 수가 작아 별도 인덱스는 두지 않는다
- 인덱스 조정 마이그레이션은 필요 없었다(SO-10)

재실행: `backend/`에서 `load` 시드 후 위 함수들을 `EXPLAIN (ANALYZE, BUFFERS)`로 감싸 실행한다.
